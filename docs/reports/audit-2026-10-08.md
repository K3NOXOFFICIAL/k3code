# Harness audit, 2026-10-08

This audit covered the Python core, the Ink TUI and the Go panes. Every suite and linter was run, the code was read for bugs, and the first launch was walked through end to end. Every item marked fixed below landed in PR #7 with a regression test.

## Fixed

### Setup, first launch and look and feel
- **Onboarding.** `k3code onboard` detects the keys you already have, a `claude` login and a local Ollama. It offers presets for the current models (Sonnet 5.5, Opus 5.5 and Haiku 5.5) and reuses keys that are already in your environment.
- **Bad API key.** A rejected key now stops at once with one message ("Set a new key with `k3code onboard`, then /retry"). Before, the turn was parked and the error was shown twice.
- **`k3code doctor`.** It now makes an authenticated call to check each key. The OmniRoute warning only appears when OmniRoute is in your chain, and a stopped daemon is no longer counted as a failure.
- **Banner.** The K3 logo is fixed. The banner shows the version, the active model, and the tool and skill counts.
- **Working line.**
  - The token count resets at the start of each turn.
  - The clock keeps its seconds after the first hour.
  - `/indicator ascii` gives a fully ASCII line.
  - The status bar no longer shows a second clock while the working line is visible.
- **Pet.** The `/pet` setting is saved across restarts. An idle pet blinks every 4.5 s. When the terminal is narrower than 100 columns, `/pet` tells you the pet is hidden.
- **TUI settings.** `/theme`, `/indicator`, `/statusbar`, `/battery`, `/mouse`, `/density`, `/busy`, `/details` and `/pet` were rejected by the gateway. They now work and are saved to `display.*`.
- **`/effort` and `/reasoning`.** Both are now sent to the model:
  - Claude models that accept it (the 5 generation, Opus 4.5 and later, Sonnet 4.6) get `output_config.effort`.
  - OpenAI reasoning models get `reasoning_effort`.
  - The levels are low, medium, high, xhigh, max and default.
  - `/reasoning show|hide` is saved.

### Panes
- Overrides in `keys.toml` were silently ignored. They now apply, both flat and under `[panes]`. An unknown mode prints a warning instead of failing silently. Global keys honor overrides in every mode.

### CI
- CI never ran on pushes to `Main`.
- Added the TUI typecheck and lint steps, and `go vet` and `-race` tests for panes.
- The vendor SHA check no longer flags files that are marked `modified`.

### Permissions and I/O (11 items)
- `&>` redirects and `git difftool` were missed by the permission check.
- Tool subprocesses now get stdin from DEVNULL.
- The 64 KiB frame limit.
- The symlink realpath check.
- The bash working directory.
- A size cap on reads.
- `config.get` redacts secrets.
- A bundle strips its metadata.
- Semver ordering of prereleases.
- `attach --readonly`.

### Turn handling (8 items)
- Where the loop-guard note is placed.
- The steer queue.
- A race that could start two tasks for one turn.
- `tool.start` sent after `done`.
- `-m` key resolution with `K3CODE_DEFAULT_MODEL`.
- Prompts queued during a job are run when it ends.
- `/model` applies per session.

### Automation and reliability (21 items)
1. MCP calls could hang forever after a reload.
2. Shell injection in automation templates.
3. The bwrap sandbox could re-bind `$HOME`. It now masks `~/.config/k3code` and `~/.ssh`.
4. Cron jobs could run twice on a DST change.
5. The classifier now follows the `__cause__` chain.
6. NetworkManager changes trigger a re-probe.
7. A goal could be saved from a stale state.
8. The scheduler's `next_run_at` advances before the run starts.
9. Ultra gathers now cancel their sibling tasks.
10. An optimizer rollback now reloads the live config.
11. Sessions are counted once per experiment.
12. `CronTrigger` no longer reuses `first_due`.
13. The journal no longer stores the args of side-effecting tools.
14. The cooldown backoff ladder.
15. `max_park_seconds` is now honored.
16. Env files with `export` lines or quotes.
17. `scope.classify` runs off the event loop.
18. Corrupt JSONL lines are skipped.
19. The `claude` CLI process wait is bounded.
20. `start_goal` on a session that no longer exists.
21. Finished subagent handles are pruned.

## Still open (filed as issues)
- Artifacts publish is not implemented (`TODO(M6)` in `artifacts_cmd.py`).
- The token count only updates when an LLM call finishes. There is no live estimate while streaming.
- A TLS certificate failure is classified as a network error, so the turn parks instead of failing.
- prompt_toolkit prints a CPR warning in some terminals.
- The tests write to the real `~/.k3code/journal`.
- The repo is not formatted by prettier or `ruff format`; about 318 TUI files and 100 core files differ. A one-off format commit plus a CI check would fix this.
- The ultracode worktree test is flaky because parallel `git worktree add` calls race.
- A project's `.k3code` config is fully trusted.
- Only one pet is on screen at a time. Issue #3 asks for several random pets and funny messages.
- The milestone exit checks are deferred: the 72 h soak, a hallway test, the scope-eval labels, live mem0 and two weeks of real use.

## Installer (owned by the install thread)

- Node, Go and bwrap are not installed automatically.
- The version name can end in `-dirty`.
- Uninstall checks the wrong XDG path.
- A relative `--prefix` breaks.
- `release.yml` runs no tests.
- The install directory is not added to PATH.
